Google Sheets Backend Setup Guide

Step 1: Open Apps Script in your Google Sheet

Open your GY Puff & Cloud Google Sheet, click Extensions → Apps Script in the top menu.

Step 2: Paste Code.gs & Set Your PIN

Delete any default code in Code.gs, paste the contents of the Code.gs file from this project, and change const ADMIN_PIN = "your-secret-pin"; to your own secret password. Click Save (Ctrl+S).

Step 3: Deploy as Web App

Click Deploy → New deployment. Select type Web app. Set:

  • Execute as: Me
  • Who has access: Anyone

Click Deploy, authorize permissions if asked, and copy the generated Web app URL (https://script.google.com/macros/s/.../exec).

Step 4: Connect to Website

Paste that Web App URL into js/config.js inside APPS_SCRIPT_URL: "..." (or test it immediately in the Settings & Sync tab).
